# Работа с swgPanel

Команды установки, обновления и удаления описаны в [руководстве по эксплуатации](docs/operations.md).
Перед запуском на сервере проверьте выбранную роль и способ установки через `--dry-run`.
Для автоматизации задавайте ответы через переменные окружения. Интерактивные вопросы читаются из терминала.

Узел сам подключается к панели по HTTPS. Для повторной установки зарегистрированного узла используйте
его сохранённый токен. Для новой регистрации создайте токен на странице «Узлы». В роли `master`
установщик регистрирует локальный узел автоматически. Управляйте данными через панель и [API](docs/api.md).

Команда обновления в терминале обслуживает текущую машину. Обновление из интерфейса панели также
запрашивает обновление у узлов, которые поддерживают эту операцию.
