# Сборка WDTT (ildarmaga)

[build.sh](build.sh) собирает сервер из `server/cmd` зафиксированного коммита `ef697994`
с патчем [wdtt-ildarmaga.patch](wdtt-ildarmaga.patch). Выпуск `1.5.0-4` основан на
доступных исходниках `v1.5.0`. Для сборки нужны Git и Go.

```bash
bash build.sh
GOARCH=arm64 bash build.sh
```

По умолчанию результат записывается в `wdtt-ildarmaga-server-<архитектура>`.
Первый аргумент переопределяет путь. `-iface`, `-wg-addr` и `-mtu` задают параметры
интерфейса, `-max-users` задаёт лимит экземпляра. При `-no-nat` NAT и системные
настройки обслуживает узел. `-dns` передаёт DNS-адреса в клиентскую конфигурацию.

Сведения о лицензии и исходниках приведены в [уведомлениях о сторонних компонентах](../../../docs/THIRD-PARTY.md).
