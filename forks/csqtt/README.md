# Сборка csqtt

[build.sh](build.sh) собирает сервер ветки 2.1, [2.5/build.sh](2.5/build.sh) использует
свой коммит и патч для ветки 2.5. Нужны Git, Cargo, Rust 1.97.1 (через rustup), Zig и
cargo-zigbuild. Резервная загрузка исходников 2.5 требует curl и проверяет SHA-256 архива
и патча.

```bash
bash build.sh /tmp/csqtt-out amd64
bash 2.5/build.sh /tmp/csqtt-25-out arm64
```

Поддерживаются `amd64` и `arm64`. По умолчанию выбирается `amd64`.

`--iface` задаёт имя TUN-интерфейса, `--tun-addr` задаёт адрес и подсеть (только `/24`).
`--no-web` отключает встроенную панель и вспомогательные сокеты. `--desired` задаёт путь
к списку паролей, который сервер читает при запуске, по `SIGHUP` и при изменении файла.
`--no-nat` принимается для совместимости и не влияет на работу. `--max-passwords`
применяется только во встроенной панели.

```json
{
  "passwords": [
    { "password": "<пароль>", "name": "alice", "expires_at": 0, "vk_hash": "", "is_deactivated": false }
  ]
}
```

Для каждого пароля `expires_at` задаётся в секундах Unix (0 — бессрочно).
Панель управляет этим списком, сервер хранит привязки и счётчики. Основной пароль
передаётся отдельно через `--password`.

Условия использования и ссылки на исходники приведены в [уведомлениях о сторонних компонентах](../../docs/THIRD-PARTY.md#csqtt-noncommercial).
